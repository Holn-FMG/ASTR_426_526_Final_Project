# Olwyn's Code Folder
This folder has Olwyn's code and data for the project.
***astr_GaiaList has most of what you're looking for -- all of the queries to GAIA are in this location. They involve searching for multiple filters and searching up different flags associated with objects (ra, dec, bp, etc...)
***astr_GaiaStatsHist has the statistics associated with the RUWE values, with the given being histogram datasets saving as files directly. Here you can find the average, standard deviation, and exponential fits of RUWE values across two files, Initial Cuts and Pot Bins.
***To see how to access Astroquery.GAIA and form associated sync and async queries, see:
  https://astroquery.readthedocs.io/en/latest/gaia/gaia.html#module-astroquery.gaia
